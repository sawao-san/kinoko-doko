## 2. プロジェクト詳細（概要） （必須・20〜5,000文字）
```
【解決する課題】
近年、健康志向や自然散策・ハイキングブームに伴い、身近な公園や里山、登山ルートで自生する野生キノコに関心を持つ人々が急増しています。しかしその一方で、毎年秋を中心に毒キノコの誤食による激しい中毒事故や死亡事故が後を絶ちません。
特に「タマゴタケ（極上の可食キノコ）」と「ベニテングタケ（幻覚や中毒を起こす有毒種）」、「ヒラタケ（可食）」と「ツキヨタケ（激しい嘔吐を起こす猛毒種）」のように、色合いや生育環境が酷似した種が多く存在し、一般の散策者が肉眼や紙のポケット図鑑だけで正確に見分けるのは極めて困難です。また、「どこで見つけたか」の正確な位置や生育環境（樹種、倒木、日陰など）を散歩ルート上に体系的にマッピング・記録する手段も不足していました。

【ソリューション】
「キノコどこどこ」は、スマートフォン片手の散歩・散策中に見つけた野生キノコを、直感的なタップ操作でGPS地図上に記録し、Google Gemini 3.8 Flash のマルチモーダル画像解析によって瞬時に「食毒」「豆知識」「誤食防止ポイント」を特定・可視化するフィールドナビゲーションWebアプリケーションです。

主な機能と提供価値：
1. マルチモーダルGemini AIによる高精度キノコ鑑定：
   スマートフォンのカメラで撮影した写真から、キノコの和名・学名の候補、食用区分（「可食」「有毒」「要注意/不明」）、約100文字の生態や食文化の豆知識、そして最も重要な「誤食を防ぐための見分けの注意点（ツバ・ツボ・ヒダの色、類似毒キノコとの鑑別点）」を構造化JSONでリアルタイム出力します。
2. 色分けピンによる直感的マッピング（Leaflet / OpenStreetMap）：
   鑑定結果に基づき、可食＝エメラルドグリーン、有毒＝クリムゾンレッド、要注意＝アンバーイエローで地図上にピンを配置。タップするだけで写真、判定、豆知識、観察メモをポップアップ閲覧可能です。
3. 住所・地名検索による遠隔リサーチ機能：
   OpenStreetMap Nominatim ジオコーディングAPIと連携し、「高尾山」「軽井沢」「新宿御苑」や任意の市区町村・番地を入力するだけで地図が滑らかに移動し、散策前の下調べや過去の記録確認が可能です。
4. 安全性の徹底と免責告知：
   AI鑑定を盲信した事故を防ぐため、「※AI判定は参考情報です。絶対に自己判断で口に入れないでください」の免責表示を徹底し、毒キノコの誤信迷信や専門機関への相談を促す「キノコ散歩・安全ガイド」を完備。
5. iPhone片手操作に最適化したモバイルUI：
   親指操作域を考慮したボトムアクションバー、地図と図鑑リスト（キーワード検索・食毒フィルター・統計サマリー）のワンタップ切り替え、LocalStorage によるオフライン耐性・高速なデータ保持を提供します。

【システム構成】
・フロントエンド（Client SPA）：
  - React 19 + TypeScript + Vite による超高速レスポンス
  - Tailwind CSS 4（セーフエリア・Retina高精細アイコン対応）
  - Leaflet.js 1.9 + OpenStreetMap タイルレンダラー
  - HTML5 Geolocation API（現在地自動取得・追従ジャンプ）
・バックエンド（Server）：
  - Node.js + Express
  - OpenStreetMap Nominatim ジオコーディング プロキシエンドポイント（/api/geocode）
・AIエンジン（AI Engine）：
  - Google Gemini 3.8 Flash（@google/genai TypeScript SDK）
  - Base64画像入力を受け、ResponseSchema（JSON Schema）による厳密な型付け出力（ハルシネーションの防止・安定したフロントエンド連携）
・インフラ・ホスティング：
  - Google Cloud Run（HTTPS環境・高速コンテナ実行）
・データ＆アナリティクス層（Google Cloud）：
  - Google BigQuery: 観測データのストリーミング・日次パーティション（PARTITION BY DATE）・数年間の「当たり年」生態分析
  - Google Cloud Storage: 観測写真のアーカイブ（gs://kinoko-archive/images/...）
  - ブラウザ LocalStorage（オフライン即時キャッシュ）
```
