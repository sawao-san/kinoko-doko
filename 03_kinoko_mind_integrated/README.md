# 🍄 Nagano Mind × キノコどこどこ 統合システム (Kinoko Mind Integrated)

> **Google Cloud Builders Day 成果物統合プロジェクト**  
> **チーム: Nagano Mind × 原田さん（キノコどこどこ）**

本リポジトリは、**「ユーザー様が開発された信州キノコ専門家黒板（Nagano Mind）」** と **「原田さんが開発されたキノコマップ（キノコどこどこ）」** を真に合体させた統合Webアプリケーションです。

---

## 🌟 コア機能（3ペイン・フル統合ワークスペース）

```text
+-------------------------------------------------------------------------------------------------------+
| 🍄 Nagano Mind × キノコどこどこ 統合システム                                                         |
+-----------------------------------+-----------------------------------+-------------------------------+
| 【左ペイン】ノート ＆ ファインマン採点 | 【中央ペイン】実物キノコ検索ギャラリー| 【右ペイン】原田さんのキノコマップ    |
| 📝 Canvas & AI赤ペン添削          | 📷 検索写真 ＆ 生態ビジュアル     | 🍄 キノコどこどこ（直接合体）     |
|                                   |                                   |                               |
| ・キノコの手描きスケッチ & 矢印   | ・説明したキノコのWikipedia /     | ・原田さんの Leaflet マップ   |
| ・音声 / テキストで特徴を説明     |   Wikimedia実物写真を自動検索表示 |   （採取ピン・GPS・同定機能） |
| ・小学生＆専門家エージェント採点  | ・描いた絵と実物写真の並列比較    | ・信州4エリア生息地ピン連携   |
+-----------------------------------+-----------------------------------+-------------------------------+
```

### 1. 📝 左ペイン：ホワイトボード ＆ ファインマン説明・採点
- 手書きペン、図形、矢印、テキスト入力、マイク音声書き起こしに対応。
- ユーザーがキノコの特徴（カサの形・色、ヒダ、ツバ、ツボ、生えている樹種）を図解・説明。
- **3人の専門AIエージェント**（小学生エージェント、キノコ生態学エージェント、赤ペン先生）が、形態描写の正確さ、誤食防止の注意点、食毒の安全性を多角的に採点。

### 2. 📷 中央ペイン：説明したキノコの実物検索画像ギャラリー
- 説明対象のキノコ（ベニテングタケ、タマゴタケ、ツキヨタケ、ドクツルタケ、ヤマドリタケ等）を自動判定。
- **Wikipedia REST API & Wikimedia Commons API** と連携し、高解像度の実物生態写真をリアルタイム検索・自動取得して複数枚グリッド表示。
- **「描いた絵と並べて比較（compareSketchMode）」** ボタンで、自分の手描きスケッチと実物キノコ写真を並列比較可能。
- 食毒区分バッジ、生息環境、Wikipedia公式図鑑への外部リンクも表示。

### 3. 🗺️ 右ペイン：原田さんの「キノコどこどこ」合体埋め込み
- 右ペインのタブから **「🍄 原田さんのキノコどこどこ」** をワンクリック選択。
- 原田さんの成果物アプリ（`http://localhost:3001` または Cloud Run 本番URL）を直接 iframe 埋め込み・合体表示。
- 原田さんの採取ピンデータ、散策ルート、AI同定機能を左ペインのファインマン学習と同時に活用可能。

## 🚀 ローカル起動方法

```powershell
# 依存関係のインストール
npm install

# 開発サーバー起動（ポート3000）
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

---

## 🐳 Google Cloud Run デプロイ

単体で Google Cloud Run へコンテナデプロイ可能です：

```powershell
gcloud run deploy kinoko-mind-integrated `
  --source . `
  --region asia-northeast1 `
  --allow-unauthenticated
```
